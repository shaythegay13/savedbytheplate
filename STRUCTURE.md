## Lastmod Maintenance

Update the `<lastmod>` date in `sitemap.xml` when pages change. For a Vite SPA, consider automating this in the build process using a sitemap generation script. Recommended package: `vite-plugin-sitemap`.

### Automated Sitemap (Optional Enhancement)
```bash
npm install vite-plugin-sitemap
```

```ts
// vite.config.ts
import { generateSitemap } from 'vite-plugin-sitemap';

export default defineConfig({
  plugins: [
    generateSitemap({
      hostname: 'https://www.savedbytheplate.org',
      routes: [
        '/',
        '/about',
        '/education',
        '/local-food',
        '/local-food/map',
        '/local-food/garden-planner',
        '/premium',
        '/terms',
        '/privacy',
      ],
      exclude: ['/auth', '/profile', '/coming-soon', '/foraging-test'],
      outDir: 'dist',
    })
  ]
});
```
